> Natural Language Processing (NLP) tool for sentiment scoring, keyword extraction, and text readability metrics.

---

## 🌟 Features

- **😊 Sentiment Scoring**: Calculates positive vs negative sentiment polarity ratio.
- **🏷️ Keyword Extraction**: Frequency analysis with automatic stopword removal.
- **📖 Readability Metrics**: Sentence length and word density breakdown.

---

## 🚀 Quick Start

```bash
git clone https://github.com/msyahirmahmud/text-insight-nlp.git
cd text-insight-nlp
python3 main.py
```

Run test suite:
```bash
python3 -m unittest discover tests
```
